## ✨ Ключевые возможности

- 🌊 **«Моя волна» и персональные станции**:
  - Быстрое переключение между *Моей волной*, *Открытиями*, *Хитами*, а также настроениями (*Энергия*, *Спокойствие*, *Фокус*, *В дороге* и др.).
  - Система рекомендаций с отправкой обратной связи (лайки, дизлайки, пропуски).

- 🎧 **Интеллектуальный DJ-режим (Smart Transition & Drop)**:
  - Плавное гармоническое сведение треков по музыкальным тактам и фразам.
  - Детекция вокала во избежание наложения голоса одного трека на другой.
  - Функция **«⚡ ДРОП»** (`D`) — мгновенный переход на самый мощный бит следующего трека.

- 🎤 **Полноэкранный текст песни (Spotify-style)**:
  - Запуск в один клик или по клавише `T`.
  - Динамическая кинетическая автопрокрутка, центрирование активной строки, чистая контрастная типографика без размытия и неонового мыла.
  - Атмосферный адаптивный фон на базе обложки текущего трека.

- ⚡ **Ультра-низкое потребление ресурсов и 0% GPU в фоне**:
  - В активном режиме оптимизированный 30 FPS холст визуализатора и композитные анимации.
  - **Мгновенная заморозка при потере фокуса**: если поверх открыт браузер, игра или другое окно, анимации и рендер визуализатора останавливаются на 0 FPS (0% GPU).
  - Фоновый тримминг памяти рабочих наборов (`SetProcessWorkingSetSize`) для всех процессов WebView2.

- 🔐 **Удобная и безопасная авторизация**:
  - Официальный вход через **Яндекс ID** в нативном защищенном окне.
  - Поддержка быстрого входа **по QR-коду** из мобильного приложения Яндекс, по телефону или логину/паролю.
  - Автоматический перехват токена без необходимости вручную искать его в DevTools.
  - Безопасное хранение токена в защищенном пользовательском хранилище AppData (вне директории репозитория).

- 🎛️ **10-полосный эквалайзер Studio EQ**:
  - Готовые студийные пресеты (Bass Boost, Vocal, Club, Rock, Acoustic, Flat).
  - Точная ручная настройка частот на Web Audio API.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| <kbd>Пробел</kbd> | Воспроизведение / Пауза |
| <kbd>Ctrl</kbd> + <kbd>→</kbd> | Следующий трек |
| <kbd>Ctrl</kbd> + <kbd>←</kbd> | Предыдущий трек |
| <kbd>→</kbd> / <kbd>←</kbd> | Перемотка на 5 секунд вперед / назад |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Регулировка громкости (+5% / -5%) |
| <kbd>D</kbd> | Мгновенное клубное сведение (DJ Дроп) |
| <kbd>T</kbd> | Открыть / закрыть полноэкранный текст песни |
| <kbd>L</kbd> | Поставить отметку «Мне нравится» |
| <kbd>S</kbd> | Режим случайного воспроизведения (Shuffle) |
| <kbd>M</kbd> | Заглушить звук (Mute) |
| <kbd>Esc</kbd> | Закрыть модальные окна / полноэкранный текст |

## 📦 Скачать и запустить

Готовый портативный исполняемый файл доступен на странице [Releases](https://github.com/playjymer/ymusic/releases):

1. Скачайте архив `ymusic-windows-x64.zip` или файл `ymusic.exe`.
2. Запустите `ymusic.exe`.
3. Нажмите **«Войти через Яндекс ID»** и отсканируйте QR-код в мобильном приложении Яндекс либо введите логин.
4. Готово!

## 🛠️ Сборка из исходников

### Требования
- [Rust](https://www.rust-lang.org/) (версия 1.80+)
- [Node.js](https://nodejs.org/) (версия 18+)
- Установленный WebView2 (встроен в Windows 10/11)

### Инструкция

```bash
# Клонируйте репозиторий
git clone https://github.com/playjymer/ymusic.git
cd ymusic

# Установите зависимости фронтенда
npm install

# Сборка релизной версии
cd src-tauri
cargo build --release
```

Готовый бинарный файл будет находиться в директории:
`src-tauri/target/release/ymusic.exe`

## 🔒 Безопасность и конфиденциальность

- Приложение взаимодействует исключительно с официальными защищенными эндпоинтами Яндекс Музыки по HTTPS.
- Пароли нигде не сохраняются: авторизация происходит на стороне `passport.yandex.ru`.
- Авторизационный токен хранится локально на вашем компьютере в защищенной пользовательской директории `%APPDATA%\ymusic` и никогда никуда не передается.
